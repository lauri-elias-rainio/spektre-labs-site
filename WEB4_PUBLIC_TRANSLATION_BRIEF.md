# Web4 Public Translation Brief

Internal standard:

> frontier architecture in, mainstream consequence out.

The public does not need the internal Web4 syntax first. The public needs:

- what hurts now
- what changes immediately
- what can be proven
- what to do next

## Public Door

Headline:

> The internet, cleaned up.

Subline:

> Spektre is a cleaner, safer browser for the next internet: fewer distractions,
> clearer trust, one place to work, and AI that acts inside the page instead of
> floating beside it.

## Translation Table

| Internal Web4 | Public language |
| --- | --- |
| owned path | a cleaner, safer way through the internet |

| policy-bound agent | AI can help on the page, and you can see what it did |
| resource rail | every payment funds the next shipped improvement |
